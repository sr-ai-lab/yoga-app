# 今日のヨガ(仮)

スマートフォンから**2タップ**で「今日やるヨガ」が決まり、そのままYouTubeで再生できるWebアプリです。

**本アプリは非公式の個人プロジェクトです。紹介する動画の制作者・運営者とは関係ありません。動画に関する権利は各権利者に帰属し、本アプリはYouTube上の公開動画へのリンクを提供するものです。**

設計の詳細は [docs/DESIGN.md](docs/DESIGN.md) を参照してください(本アプリの唯一の正式仕様です)。

---

## これは何か

- 対象動画: B-flow / B-flow Studio の**一般公開・無料視聴可能な動画のみ**(旧B-life時代の動画も、同一チャンネルであるB-flowの一部として扱う)
- 時間(10/20/30/45/60分)とモード(6種)を選ぶだけで、動画を1本、または複数本の「コース」で提案
- ログイン・個人情報なし。端末の `localStorage` に前回選択した時間・モードのみを保存
- サーバー不要、GitHub Pagesで公開する静的サイト

## 使い方

1. 公開URL(`https://sr-ai-lab.github.io/yoga-app/`)をスマートフォンのブラウザで開く
2. 時間 → モードの順にタップすると、動画(またはコース)が提案される
3. 「▶ 再生」または「▶ まとめて再生」でYouTubeへ
4. 共有メニューから「ホーム画面に追加」すると、アプリのように起動できます

## 技術構成

| 項目 | 選定 |
|---|---|
| フロントエンド | 素のHTML/CSS/JavaScript(ビルド不要、npm依存なし) |
| データ | `data/videos.json` 等の静的JSON。通常利用時に外部APIは呼ばない |
| 状態管理 | プレーンなJSオブジェクト + `localStorage` |
| PWA | `manifest.json`(ホーム画面追加用。Service Workerなし) |
| 更新スクリプト | Node.js 18+(`scripts/`。依存パッケージなし) |
| ホスティング | GitHub Pages |

詳細と設計判断の理由は [docs/DESIGN.md](docs/DESIGN.md) を参照してください。

## ローカルでの動作確認

ビルド不要です。プロジェクトルートで簡易HTTPサーバーを起動して確認できます。

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173/` を開いてください(`fetch` で `data/*.json` を読み込むため、`file://` では動作しません)。

## 公開(GitHub Pages)

0. **(Public化前)** 開発中はPrivateリポジトリのままでよい。Publicに切り替える前に、必ず以下の「Public化前のチェックリスト」を実施する
1. リポジトリをPublicに切り替える
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` に設定
3. `https://sr-ai-lab.github.io/yoga-app/` で公開される
4. 以後、`git push` のたびに自動反映(反映まで数分)
5. スマートフォンでURLを開き、共有メニューから「ホーム画面に追加」

### Public化前のチェックリスト

Publicに切り替える前に、リポジトリの全コミット履歴を対象に秘密情報(APIキー・トークン等)が含まれていないか必ず確認する。

- [ ] `git log -p -- .env` 等、APIキーを含みうるファイルの履歴を直接確認した
- [ ] 可能であれば gitleaks 等のシークレットスキャンツールをリポジトリ全体に対して実行した
- [ ] 万一検出した場合は、該当キーを失効・再発行した(履歴からの削除だけでは元のキー自体は無効化されないため)

## セキュリティ・注意事項

- **APIキー**: `.env` はコミットしない(`.gitignore` で除外済み)。`.env.example` にはキー名のみ記載。万一コミットした場合はキーを失効・再発行する(履歴削除だけでは不十分)
- **個人情報**: アプリはログイン・氏名・連絡先を一切扱わない。`localStorage` に保存するのは時間・モードの選択値のみ
- **YouTubeデータの扱い**: リポジトリに保存するのは「動画ID・タイトル・長さ」という事実データと自作の分類のみ。APIレスポンスの丸ごと保存・再配布はしない
- **著作権**: 動画の埋め込み・ダウンロードはせず、YouTube公式ページ/アプリへのリンクのみ
- **`watch_videos?video_ids=`**: 非公式のURLエンドポイントを使用している。将来無効化される可能性があるが、その場合も各動画の個別リンクがフォールバックとして機能する
